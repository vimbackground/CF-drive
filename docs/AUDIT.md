# CF-drive 当前审计基线

审计范围：`worker.js`、部署配置模板、测试与当前文档。此文件描述新部署基线的现状，不包含历史版本迁移结论。

## 已确认的控制措施

| 范畴 | 当前控制 |
| --- | --- |
| 启动前提 | 主站要求 R2、D1 与所有者公钥；未认领时仅开放签名保护的初始化流程。 |
| 管理认证 | 管理员密码以 PBKDF2-HMAC-SHA-256、100,000 次迭代的校验记录保存于 D1；7 天 HMAC 会话 Cookie 使用 Worker 生成的独立签名密钥。 |
| 写操作防护 | 已登录的危险 API 必须通过同源 CSRF 校验。 |
| 认证滥用 | 管理登录、分享密码、WebDAV Basic Auth 连续失败 5 次后锁定 15 分钟。 |
| 分享 | 独立的 D1 内部签名密钥；密码、过期、下载次数、授权版本与下载租约全部由服务端验证。 |
| Range 与限次 | 同一下载会话的 Range 重试复用租约，不重复消耗分享额度。 |
| 存储节点 | `/api/node/*` 仅接受 D1 生成的独立 Token，不复用管理员密码。 |
| 路径与元数据 | 虚拟路径校验拒绝遍历；D1 目录索引使用比较并交换更新。 |
| WebDAV | 默认关闭；独立 Basic Auth、ETag 条件、排他锁与上传大小上限。 |
| 浏览器响应 | HTML 使用无缓存、防 MIME 嗅探、防嵌入和受限浏览器能力响应头。 |

## 已知边界

- `worker.js` 是单文件应用，网页 UI 与服务端路由共存；修改任一部分都应运行完整回归测试。
- D1 采用键值记录模型，并非通用关系型业务数据库；大规模查询和管理功能应先评估 D1 限制。
- R2 删除与外部节点分片清理由 `ctx.waitUntil()` 延续执行。应定期查看日志并用孤儿扫描核对异常中断后的残留对象。
- WebDAV 只声明 DAV Class 1，不支持死属性、`PROPPATCH` 或完整桌面办公客户端扩展。
- 容量页面按 10 GiB/节点展示估算总量，不能替代 Cloudflare 账单或配额监控。

## 发布前验证

```powershell
npm.cmd run verify
```

当前测试覆盖：路径边界、未认领实例失败关闭、所有者签名初始化、D1 密码登录、HTML 安全头、存储节点凭据隔离、匿名路径关闭、WebDAV 认证与基础生命周期、ETag、锁、认证限速、分享次数/Range 与改密失效。

## 运维要求

- 在 Cloudflare WAF/Rate Limiting 设置边缘限速，尤其保护登录、分享密码和 WebDAV。
- 任何新认证、存储或匿名访问方案都必须使用独立密钥/绑定，并添加测试。
- 任何数据模型变更都必须提供迁移、回退和恢复演练；禁止以静默兼容分支替代迁移方案。
- 妥善备份所有者私钥，并将 `.cf-drive/`、`.dev.vars`、`.env` 与凭据文件保持在 Git 之外。
